# Repository Overview

This repository accompanies the research paper on atmospheric pollutant reconstruction during major urban events. While the paper primarily presents the reconstruction of carbon monoxide (CO) concentrations over the Jakarta Metropolitan Area and Bangkok City during major fire events, this repository contains the broader implementation framework developed throughout the research process.

The repository includes multiple experimental configurations covering:

- Different pollutants:
  - Carbon Monoxide (CO)
  - Nitrogen Dioxide (NO₂)

- Different spatial domains:
  - Western Java centroids
  - Jakarta Metropolitan Area
  - Bangkok Metropolitan Area

- Different event scenarios:
  - Fire-related events
  - Traffic-related emission events

The purpose of this repository is to provide sufficient implementation details, preprocessing workflows, and experimental configurations so that other researchers can reproduce, adapt, and extend the study.

---

# Repository Structure

## `ScriptGEE/`

Contains Google Earth Engine (GEE) scripts and extraction workflows used for data acquisition and preprocessing.

The scripts demonstrate how to extract:

- Pollutant concentrations (CO and NO₂)
- Horizontal wind components
- Vertical wind components
- Latitude and longitude information

under both NO₂ and CO spatial grid resolutions.

These scripts serve as a guide for reproducing the environmental data collection pipeline used in the study.

## Scenario Folders

### `BangkokCity/`
### `JakartaMetropolitanArea/`
### `WestJava_Banten_Jakarta_SpatialCentroid/`
### `WestJava_Banten_Jakarta_SpatialGrid/`

These directories contain the experimental implementations and configurations for CO and NO₂ from data preprocessing, training model, to imputation and reconstruction tasks from 2023–2025.

The folders include variations in:

- Spatial representations
- Grid configurations
- Reconstruction settings
- Event-specific scenarios

allowing users to compare different modeling approaches and regional setups used during the development stage of the research.

# Data Availability

Due to the large storage and memory requirements, the extracted datasets, reconstructed outputs, and imputed results generated by the models are hosted externally.

The data can be accessed here: [Dataset Access](http://u.pc.cd/mTF7)

The external dataset includes:

- Extracted atmospheric variables
- Reconstructed pollutant concentration outputs
- Imputed missing-value datasets

# Reproducibility

To reproduce the experiments:

1. Use the scripts inside `ScriptGEE/` to extract environmental and pollutant variables from Google Earth Engine.
2. Select one of the provided spatial scenario folders.
3. Configure the desired pollutant type (CO or NO₂), spatial domain, and event scenario.
4. Run the reconstruction and imputation pipelines according to the provided implementation files.
5. Compare generated outputs with the externally hosted datasets for verification.

This repository is intended to support transparency, reproducibility, and further research development in atmospheric pollutant reconstruction and environmental spatiotemporal modeling.
